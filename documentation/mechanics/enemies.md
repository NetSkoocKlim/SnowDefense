# Реализация врагов

Этот документ описывает все ключевые особенности и детали реализации системы врагов (`Enemy`) в проекте.

---

1. Архитектура классов

   - `Enemy` (базовый класс) — содержит общую логику для всех типов врагов: инициализацию, перерождение (`reset`), спавн (`spawn`), обработку коллизий, здоровье, передвижение, атаку, отрисовку.

   - `DefaultEnemy` (наследник `Enemy`) — простой тип врага «обычный» (`common`) с фиксированными размерами, скоростью и анимациями ходьбы/атаки.

   - `EliteEnemy` (наследник `Enemy`) — «элитный» тип врага (`elite`) с дополнительными механиками: возможность скрываться (`hide`), ускорение после появления, своя вероятность исчезновения.

2. Конструктор и поля базового класса (`Enemy`)
    1. Основные поля:
        - `width`, `height` - размера объекта на канвасе (с учётом глобального масштаба `Canvas.scale`).
          > **Примечание**: все значения ширины и высоты 
          > рассчитываются на основе исходных 
          > (родных) размеров спрайтов (в пикселях), задаются в классах `DefaultEnemy` и `EliteEnemy`,
          > где, затем умножаются на глобальный масштаб Canvas.scale, 
          > что обеспечивает корректный размер на разных разрешениях экрана.
        - `speed` - скорость перемещения
        - `kind` - строковый идентификатор типа ("common" или "elite")
        - `isAlive` - логическая переменная, отвечающая за то, жив ли сейчас объект
    2. Здоровье и вознаграждение:
        - `maxHP`, `currentHP` — максимальное и текущее здоровье.
        - `damage` — урон, наносимый базе при атаке.
        - `reward` — количество очков за убийство.
    3. Таймеры и кулдауны:
       - `attackCooldown` — время между атаками (сек).
       - `attackCooldownTimer`: `CooldownTimer` — управляет паузой и возобновлением атак.
    4. Анимация:
       - `enemyAnimator`: `EnemyAnimator` — объект, отвечающий за переключение спрайтов и кадровую логику.
       - `currentState` — текущее состояние (Move, Attack, Death, Hidden).
    5. Позиционирование:
       - `position`: {x, y} — координаты левого верхнего угла врага.
       - `velocity`: {x, y} — вектор движения.
       - `side` — сторона спавна (1: слева, 2: снизу, 3: справа, 4: сверху).
    6. Коллизии:
       - `headCollisionScales`, `bodyCollisionScales` — коэффициенты масштабирования зоны головы и тела.
       - `collisions`: `{ head: PolygonCollision, body: PolygonCollision }`.
    7. Отрисовка полоски здоровья:
       - `healthBarHeight`, `healthBarOffset` — настройки графики полоски.

3. Жизненный цикл врага:
    1. `reset()`:
   
        Сбрасывает все поля в первоначальное состояние:
       - `isAlive = false`.
       - Отключает и сбрасывает таймеры (`attackCooldownTimer`, `frameDelayTimer` аниматора).
       - `currentHp = maxHP`.
       
    2. `spawn({side})`:
       1. Выбор стороны:
          - Если `side` не передан, то выбирается случайно от 1 до 4.
       2. Позиционирование и ориентация:
          - Для каждой стороны меняются `width`/`height` местами (ориентация спрайта).

          - x, y устанавливаются так, чтобы враг появлялся за пределами холста, на рандомной координате вдоль стороны.

          - `velocity` направлен к центру.
       
       3. Активация:
          - `isAlive = true`, добавление коллизий (`addCollisions()`), переключение в движение (`setMove()`), запуск анимации.

4. Добавление коллизий: `addCollision()`:
   1. Расчёт размеров зон:

      - На основе `headCollisionScales` и `bodyCollisionScales`, отдельно для чётных (2,4) и нечётных (1,3) сторон.

   2. Позиция зон:

      - Голова и тело располагаются относительно `this.position` по формулам для каждой стороны.

   3. Создание коллизий:

      - `new PolygonCollision(position, getRectangleBorders(width, height), rotationAngle=0)`.

   4. Вычисление `headCenter`:

      - Требуется для проверки доступа к базе (центр головы и коллизия с `Game.base.collision`).

5. Поведение и состояния
   1. Движение: `move()`
      - Сдвиг позиций и коллизий на `velocity * speed`.

      - При достижении базы (`isBaseAccessible()`) — переход в состояние атаки (`setAttack()`).

      - В `EliteEnemy`: шанс исчезновения и переход в скрытое состояние

   2. Атака: `handleAttack()` + `attack()`
      1. Логика анимации:

         - Ждём, пока анимация дойдёт до последнего кадра → вызываем `attack()`, перезапускаем кулдаун.

      2. `attack()`:

         - Наносит урон базе.

         - Если здоровье базы ≤ 0 → останавливает игру, показывает Game Over
   3. Смерть: `handleDamage(damage)` + `setDeath()`
      1. При получении урона:
         - Если `currentHP - damage ≤ 0` → `setDeath(),` начисление очков, обновление счётчиков спавнера.
         - Иначе `currentHP -= damage`.
      2. `setDeath()`:
         - Останавливает анимацию, выключает таймеры, флаг `isAlive=false`, сбрасывает HP на max.
   4. `EliteEnemy` - скрытие:
      - Поле `hideTimer`: `CooldownTimer` (3 сек).
      - `move()` переопределён: при `state === "Move"` с вероятностью `disappearChance` (0.0006) враг скрывается (`setHide()`), скорость уменьшается.
      - В состоянии Hidden враг движется без коллизий атаки, пока таймер не истечёт, затем восстанавливает скорость и возвращается в состояние Move.

6. Отрисовка: `draw({collision = false})`:
   1. Поворот спрайта:

        - `rotateImg()` — поворот `canvas.ctx.rotate(...)` и `translate(...)` в зависимости от стороны.

   2. Рисование спрайта:

      - `ctx.drawImage(spriteImg, srcX, srcY, srcW, srcH, destX=0, destY=0, destW=scaledW, destH=scaledH)`.

   3. Рисование полоски здоровья:

      - Серый фон + цветная заливка пропорционально урону (`getHealthColor()`).

   4. (Опционально) отладочные коллизии:

      - При `collision=true` рисует `head.draw()`, `body.draw()`.
