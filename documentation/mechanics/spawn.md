# Механизм спавна

Основная идея механизма — использование заранее 
инициализированных массивов экземпляров классов, 
из которых при необходимости выбираются «свободные» 
объекты для спавна. Такой подход позволяет 
избежать частого создания и удаления объектов, 
что повышает производительность игры.
 

----

1. Принцип работы через инициализированные массивы

   1. Предварительное выделение. 
      - При старте уровня создаются массивы объектов (враги и мины) требуемого размера. 
      Объекты в них находятся в неактивном состоянии (`isAlive = false` или` isExplode = true`).

   2. Повторное использование. 
      - Для спавна ищется первый свободный экземпляр в массиве. 
      Он «активируется» (метод `spawn`), а после смерти/взрыва возвращается в пул свободных.

   3. Избежание выделения памяти во время игры. 
      - Ни один из объектов не создаётся и не удаляется во время цикла игры, 
      что минимизирует паузы из-за сборщика мусора.

2. Реализация в классах

    1. `EnemySpawner`
       - Статические массивы:
         - `enemies` — массив объектов `DefaultEnemy` (обычные враги)

         - `eliteEnemies` — массив объектов `EliteEnemy` (элитные враги)

       - Инициализация:

         - `init()` — вызывает `initTimer()` и `initEnemies()`.

         - `initTimer()` — создаёт `CooldownTimer` для управления периодическим спавном.

         - `initEnemies()` — заполняет оба массива по `maxEnemyCount` экземплярами врагов.

       - Спавн:

         - `spawnEnemy({ side, count, isElite })` — запускает до count попыток спавна. Для каждого:

         - Генерируется случайное число для определения элиты.

         - Перебирается соответствующий массив (`eliteEnemies` или `enemies`) в поисках первого объекта с `isAlive === false`.

         - Вызывается `enemy.spawn({ side })` и увеличивается счётчик `enemiesAlive`.

       - Настройка частоты спавна:

         - `setSpawnRate(spawnCount, seconds)` — задаёт `onComplete` у таймера на вызов spawnEnemy каждые `seconds` секунд.

         - `unsetSpawnRate()` — приостанавливает и сбрасывает таймер.
    2. `MineSpawner`
       - Статический массив:

         - `mines` — массив объектов `Mine`, вместимостью `maxMinesCount`.

       - Инициализация:

         - `init()` — вызывает `initTimer()` и `initMines()`.

         - `initMines()` — заполняет массив mines по maxMinesCount экземплярами Mine.

       - Спавн:

         - `spawnMine({ side, count })` — для каждого счётчика пытается найти `Mine` с `isExplode === true`, затем вызывает `mine.spawn({ side })`.

       - Частота спавна:

         - `setSpawnRate(seconds)` — аналогично EnemySpawner, но количество спавнов фиксировано равно 1.

         - `unsetSpawnRate()` — останавливает таймер.

3. Рекомендации
   - Объём пула (`maxEnemyCount`, `maxMinesCount`) должен превышать максимально возможное число одновременно активных объектов.

   - Сброс состояния. Метод `reset()` у спавнеров возвращает все объекты в исходное состояние и останавливает таймеры.

   - Гибкость. Используя флаги `isElite` и параметры спавна, легко контролировать баланс и разнообразие игровых сцен.
